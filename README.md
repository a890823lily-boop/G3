# 三年級識字樂園

👉 <strong>網站連結：</strong>[https://a890823lily-boop.github.io/G3/](https://a890823lily-boop.github.io/G3/)

用手機打開上面的連結，可以「加入主畫面」當 APP 使用。

國小三年級國語識字學習網站，內容為<strong>康軒版國語三上（第五冊）</strong>第一課到第十二課的生字（寫字 162 字、認讀字 40 字）。純 HTML、CSS、JavaScript 製作，不需安裝任何套件，手機、平板、電腦都能用。

## 功能

- **首頁**：依課次列出生字，黑色是寫字、綠色虛線框是認讀字，顯示每一課的學習進度
- **生字卡**：國字（楷書、田字格）、直式注音、部首、筆畫、詞語、例句；可點「🔊」用瀏覽器語音朗讀；按「我學會了」得到星星 ⭐
- **寫字練習**：用手指或滑鼠在田字格裡寫字，可開關描紅（只練寫字，不含認讀字）
- **小測驗**：看注音選字、部首挑戰、句子填空、綜合挑戰，每回 10 題
- **成語**：依課次分組
  - 📖 **成語卡**：成語（每個字附注音）、簡單解釋、例句，可朗讀
  - 🔗 **解釋配對**：先點成語、再點解釋，配成一對；零失誤會撒花
  - ✏️ **句子填空**：選出句子裡缺少的成語，答完會複習答錯的成語
- **貓咪遊戲樂園**（可選課次範圍，音效可開關，破紀錄會撒花）
  - 🐟 **貓咪接魚**：看注音，點跑道移動小貓，接住寫著正確國字的魚；接錯少一顆愛心，魚會越掉越快
  - 🐭 **貓咪打老鼠**：60 秒內，點拿著正確國字的老鼠；連續答對有連擊加分，打錯扣 3 秒
  - 🃏 **貓咪翻翻樂**：翻牌把「國字」和它的「注音」配成一對，次數越少越厲害
- **錯字本**：答錯的字自動收錄，再答對就移除；可一鍵做錯字複習測驗

學習紀錄（星星、錯字）存在瀏覽器的 localStorage 裡，不會上傳到任何地方。

## 增加或修改生字

所有生字都在 `js/data.js`，生字依課本「本冊生字」頁整理；注音、部首、筆畫依教育部《重編國語辭典修訂本》，破音字採用課文中的讀音。詞語與例句為自編，不是課文原句。

每一課可以在 `name: ''` 填入課名，就會顯示在首頁和選單上。每個字的格式：

```js
{ c: '晴', zy: 'ㄑㄧㄥˊ', bs: '日', bh: 12, words: ['晴天', '晴朗'], s: '今天是晴天，我們去公園玩。' },
```

| 欄位 | 說明 |
| --- | --- |
| `c` | 生字 |
| `zy` | 注音（含聲調） |
| `bs` | 部首 |
| `bh` | 總筆畫數 |
| `words` | 詞語（第一個會用在測驗提示中） |
| `s` | 例句，必須包含這個字 |
| `r` | 寫 `r: true` 表示認讀字 |

要做三下時，可以照同樣格式新增課次。

## 增加成語

成語在 `js/idioms.js`，每一課是一組，格式：

```js
{ w: '守口如瓶', zy: 'ㄕㄡˇ ㄎㄡˇ ㄖㄨˊ ㄆㄧㄥˊ', mean: '簡單解釋', s: ['例句一，要寫出完整的守口如瓶。', '例句二'] },
```

注音每個字之間用空格分開；例句裡要寫出完整成語，填空題會自動把它挖空。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，也可以部署到 GitHub Pages。部署到 HTTPS 網址後可以「加入主畫面」安裝成 APP，離線也能用。

> 修改內容後，請把 `sw.js` 裡的 `CACHE_NAME` 版本號加一（例如 `v1` → `v2`）。
>
> 朗讀功能使用裝置內建的語音，iPhone、Android、Windows、Mac 大多內建中文語音；若沒有聲音，請在系統設定中安裝「中文（台灣）」語音。
